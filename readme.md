# 🔢 Pin Matcher  

A simple **PIN matching application** built with JavaScript to generate and verify PINs! 🚀  

## 📌 About  

The **Pin Matcher** app generates a **random 4-digit PIN** and allows the user to enter a PIN to match it. If the entered PIN matches the generated one, it displays a success message; otherwise, an error is shown.  

## 🚀 Features  

✅ **Generate a random 4-digit PIN** 🔢  
✅ **Enter and verify the PIN** using a virtual keypad ⌨️  
✅ **Show success or failure messages** 📢  
✅ **Limited attempts for security** 🔒  
✅ **Responsive design** – Works on all devices 📱💻  

## 🔧 Installation  

1. **Clone the repository**  
   
   https://github.com/sohanxrana/Pin-Matcher.git
 
2. **Navigate to the project folder**  

   cd Pin-Matcher
 
3. **Open index.html in your browser**  

Now, you're all set! 🎉  

## 🎯 How to Use  

1. Click the **Generate PIN** button to get a **random 4-digit PIN** 🎲  
2. Enter the PIN using the **virtual keypad** or keyboard ⌨️  
3. Click the **Submit** button to verify the PIN ✅  
4. If the entered PIN matches, a **success message** appears 🎉  
5. If incorrect, an **error message** is displayed ❌  
6. Limited attempts for extra security! 🔒
